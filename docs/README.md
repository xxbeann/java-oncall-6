## 구현 기능
1. 월과 시작요일 입력 기능
2. 평일 비상 근무 순서 입력 기능
3. 휴일(토요일, 일요일, 공휴일) 비상 근무 순서 입력 기능
4. 평일 + 공휴일의 경유에만 요일 뒤에 (휴일) 표기 하기
5. 근무 배정 기능

## 구현 기능 details
1. 월과 시작요일 입력 기능
    * 연도 고려 X, 2월은 28일까지 존재.
2. 평일 비상 근무 순서 입력 기능
   * 비상 근무자는 평일 순번, 휴일 순번에 각각 1회 편성되어야 한다.
   * 닉네임은 최대 5글자.
   * 5 <= 사람수 <= 35
3. 휴일(토요일, 일요일, 공휴일) 비상 근무 순서 입력 기능
   * 비상 근무자는 평일 순번, 휴일 순번에 각각 1회 편성되어야 한다.
   * 닉네임은 최대 5글자.
   * 5 <= 사람수 <= 35
   * 올바르지 않은 입력을 할 경우 [ERROR]로 시작하는 에러 메시지를 출력 후 다시 입력받는다.
   * 법정 공유일 1월 1일, 3월 1일, 5월 1일, 6월 6일, 8월 15일, 10월 3일, 10월 9일, 12월 25일
4. 평일 + 공휴일의 경유에만 요일 뒤에 (휴일) 표기 하기
5. 근무 배정 기능
